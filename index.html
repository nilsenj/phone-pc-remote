LOCAL NETWORK REMOTE CONTROL

Phone PC Remote

Use your Android phone as a trackpad, keyboard and remote for your Windows or Ubuntu computer. Pair once with a QR code; both devices communicate on your local network.

Get the Android app

Get the apps

You need the Android app and a desktop companion on the computer you want to control.

Android phone

Download the signed 0.1.26 APK from our public GitHub release. Google Play is currently limited to testers, not a public download.

Download Android APK

Windows 11 PC

Install the free Windows companion from Microsoft Store. This is an MSIX Store app, not an EXE installer. Phone-as-webcam is not supported on Windows.

Install from Microsoft Store

Ubuntu PC (beta)

Download the 0.1.26 amd64 .deb for Ubuntu 24.04+. Phone-as-webcam works in the tested VM, but physical-hardware validation and crash recovery remain incomplete.

Download Ubuntu beta

The GitHub Android APK uses a different signing certificate from Google Play. It cannot update a Play installation, or be updated by one. Switching channels may require uninstalling and can erase pairings or app data. Do not uninstall an existing Play build just to try this APK.

Connect in three steps

  1. Install the Android app and the Windows or Ubuntu companion.
  2. Connect both devices to a local network where they can reach each other; guest Wi-Fi or device isolation may block pairing.
  3. Open the desktop app and scan its pairing QR code with the Android app. Keep pairing codes private.
