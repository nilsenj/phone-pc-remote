Phone PC Remote AI setup guide

The Phone PC Remote connector lets compatible AI tools look up official downloads and guide you through pairing an Android phone with a Windows 11 PC, an Ubuntu 24.04+ PC, or a supported smart TV. MCP stands for Model Context Protocol, which is how the AI tool calls these setup tools.

The setup connector runs on the computer where you use your AI client. It returns public instructions and links. It has no access to your paired devices, screen, files, clipboard, pairing codes, or purchase information.

Download and prepare the connector

  1. Install Node.js 22 or later on the computer running your AI client.
  2. Download the Phone PC Remote MCP ZIP and checksum. Extract the entire ZIP. Keep the tools and distribution folders together.
  3. Open a terminal in the extracted folder and run the commands below. Keep the extracted folder in a permanent location so the client can find it later.
cd tools/phone-pc-remote-mcp
npm ci

Connect Codex

From the directory where you ran npm ci, run the commands for your operating system. Restart or start a new session in the same Codex installation if the tools do not show up immediately.

Windows PowerShell

codex mcp add phone-pc-remote -- node (Resolve-Path ./stdio.mjs).Path
codex mcp list

Ubuntu terminal

codex mcp add phone-pc-remote -- node "$PWD/stdio.mjs"
codex mcp list

Connect Claude Desktop or VS Code

In Claude Desktop, open Settings, then Developer, then Edit Config. Add this entry to the existing mcpServers object. Replace the sample paths with the absolute paths to Node and the extracted stdio.mjs, and restart Claude Desktop.

{
  "mcpServers": {
    "phone-pc-remote": {
      "command": "C:/Program Files/nodejs/node.exe",
      "args": ["C:/Apps/Phone-PC-Remote-MCP/tools/phone-pc-remote-mcp/stdio.mjs"]
    }
  }
}

In VS Code, run MCP: Open User Configuration from the Command Palette. Add the same entry under servers instead of mcpServers, set its type to stdio, and start the server when prompted. On Ubuntu, use command -v node and realpath stdio.mjs from the connector folder to get both paths.

This package requires a client that can start a local MCP process. There is currently no hosted connector URL or ChatGPT directory listing.

Try a question

  • “Use Phone PC Remote to give me the official Windows companion download.”
  • “Use Phone PC Remote to walk me through pairing my Android phone with Ubuntu.”
  • “My TV isn’t showing up. Use Phone PC Remote to explain what to check.”

get_install_link accepts android, windows, or ubuntu. get_setup_help accepts windows, ubuntu, or tv and returns steps and troubleshooting tips.

Troubleshooting

  • Client cannot start the connector. Check node --version, run npm ci in the connector folder, and confirm the configuration points at the extracted stdio.mjs. Use Node’s full path if the client cannot find it.
  • The AI responds without using the connector. Check that Phone PC Remote appears in your client’s tool list, enable it in the session, and ask for it by name.
  • The phone cannot find the PC or TV. Put them on the same reachable network. Guest Wi-Fi, device isolation, and VPNs can block pairing. Use Add TV for a supported smart TV and scan the companion’s pairing QR for a PC.
  • To remove the connector, run codex mcp remove phone-pc-remote or remove its configuration entry from your client and restart it.

In newer app builds, open Settings → Apps for your other devices → AI setup help on Android or Devices → AI setup help on Windows or Ubuntu to return to this guide.
