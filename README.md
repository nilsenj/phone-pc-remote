# Phone PC Remote

Control a Windows or Ubuntu computer from an Android phone over a local network.

**[Download the apps and follow the setup steps](https://nilsenj.github.io/phone-pc-remote/)**

- Android: [Google Play](https://play.google.com/store/apps/details?id=dev.phonepcremote.app) · [GitHub APK for fresh sideloads](https://github.com/nilsenj/phone-pc-remote-releases/releases/tag/android-v0.1.32). The APK cannot update earlier GitHub or Play installations.
- Windows 11 x64: [free Microsoft Store app](https://apps.microsoft.com/detail/9NP7CKV77CRK) (MSIX, not EXE).
- Ubuntu 24.04+ amd64: [0.1.27 beta `.deb`](https://github.com/nilsenj/phone-pc-remote-releases/releases/tag/desktop-v0.1.27-beta.1). Camera crash recovery and physical-hardware validation remain incomplete.

For Codex, Claude Desktop and VS Code, see the [AI setup guide](https://nilsenj.github.io/phone-pc-remote/ai.html).

See [installation and update guidance](https://github.com/nilsenj/phone-pc-remote-releases/blob/main/INSTALL.md), the [privacy policy](https://nilsenj.github.io/phone-pc-remote/privacy.html), or [report an issue](https://github.com/nilsenj/phone-pc-remote-releases/issues). No Bluetooth mode is offered in this release.

This repository hosts the public website and privacy page; application source is not published here.
